# 仓库共享版：活跃代码与文件说明

## 1. 文档用途

这份文档用于给团队成员快速说明当前仓库里“仍然活跃、仍然值得直接阅读和使用”的代码文件与关键工程文件。它不覆盖已经归档或已经判死的路线，也不把本机大体积生成物、临时扫描结果和上游依赖副本算进来。

阅读顺序建议是：

1. 先看仓库根目录 `README.md`
2. 再看 `gesture_project/docs/新对话对接_当前唯一有效入口_2026-06-12.md`
3. 需要找具体脚本时，再回到本文件

## 4. 算法训练与量化相关文件

### 4.1 算法总说明

- `gesture_project/algorithms/README.md`

### 4.2 静态卷积主线脚本

- `gesture_project/algorithms/static_cnn/train_static_cnn.py`

### 4.3 MobileNet 候选脚本

- `gesture_project/algorithms/mobilenet_candidates/train_mobilenet_candidate.py`
  作用：训练 MobileNet 家族候选模型，用于和当前 `3x3` 主线做精度、量化稳定性和 NPU 映射收益对比。
- `gesture_project/algorithms/mobilenet_candidates/README.md`
  作用：说明为什么保留 MobileNet 作为对照候选，以及如何运行相关训练命令。

## 5. 模型评估、画像和候选比较脚本

### 5.2 算子画像与周期估算脚本

- `gesture_project/algorithms/tools/profile_tflite_ops.py`

- `gesture_project/algorithms/tools/estimate_npu_cycles.py`

- `gesture_project/algorithms/tools/estimate_shape_report_cycles.py`
  作用：针对形状级统计结果补做周期估算，常用于更细的热点层分析。
- `gesture_project/algorithms/tools/estimate_candidate_cycles.py`
  作用：对候选结构或局部设计方案做周期级估算，用于快速筛除无价值方向。
- `gesture_project/algorithms/tools/static_cnn_shape_report.py`
  作用：输出静态卷积主线模型的层级形状报告，方便后续映射到 CoralNPU 回放与热点分析。
- `gesture_project/algorithms/tools/summarize_hardware_hotspots.py`
  作用：对热点层和主要算子类型做摘要，帮助判断优化资源应该集中在哪些层。

### 5.3 候选模型对比脚本

- `gesture_project/algorithms/tools/compare_model_candidates.py`
  作用：统一比较多个候选模型在精度、量化和部署导向指标上的表现。
- `gesture_project/algorithms/tools/summarize_candidate_hardware.py`
  作用：把候选模型结果整理成硬件导向摘要，是形成“算法保底线”时的重要汇总入口。
