## 0. 整个工程的总目的与总路线

这个工程不是单纯做一个手势分类模型，也不是单纯给 CoralNPU 改一个卷积内核。

它的总目标是：

```text
以 Google Coral NPU 开源仓库为基础，
围绕“面向手势识别的 RISC-V + NPU 软硬件协同优化”这件事，
通过广泛搜索候选算法、持续做软件/硬件侧试验、
并且始终用实际仿真/回放/量化结果比较优劣，
逐步收敛到当前阶段最优的手势识别部署方案。
```

也就是说，这个项目从一开始就不是：

- 只凭 PDF 设想直接上 RTL
- 只凭某个流行模型名字直接定算法
- 只凭某个单点 patch 的 intuition 就认定路线

而是强调：

```text
资料调研 -> 候选尝试 -> 真实训练/量化 -> NPUSim/official replay -> 比较优劣 -> 再收敛下一步
```

### PDF 的角色

项目最初的申请书 PDF 在：

```text
/home/steveguo/coralnpu-gesture/24348025_面向手势识别的RISC-V+NPU设计.pdf
```

它的作用是：

- 作为整个项目的大方向参考
- 说明项目最初希望探索“面向手势识别的 RISC-V NPU 设计”

但它**不是**已经验证过的技术结论来源。

新对话里应明确理解为：

```text
PDF 提供目标感和问题意识，
真正的技术路线取舍必须以 CoralNPU 实际源码、真实模型、真实仿真结果为准。
```
