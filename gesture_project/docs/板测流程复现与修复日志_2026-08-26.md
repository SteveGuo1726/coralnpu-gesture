## 3. 修复内容

`innovation_npu/board_7020/run_board_wide80_postprocess_from_wsl.sh` 原 cmd.exe 调用未设置 `GESTUREFLOW_HW_SERVER_URL`，导致 TCL 默认 `tcp:127.0.0.1:3334`。已改为显式传入：

```text
set GESTUREFLOW_HW_SERVER_URL=tcp:127.0.0.1:3121
```

同时新增 `innovation_npu/board_7020/board_status.sh` 和 `innovation_npu/board_7020/scripts/probe_hw_targets.tcl`，用于只读探测 hw_server 端口与 JTAG 目标，不烧板。

## 4. 本轮实测板测结果

```text
GESTUREFLOW_LAYER_CHAIN_HP0_FINAL_RESULT = 0x600D600D
GESTUREFLOW_LAYER_CHAIN_HP0_PROBE[122]   = 0x53C6484E   (head FNV)
GESTUREFLOW_LAYER_CHAIN_HP0_PROBE[124]   = 0xABBC5831   (GAP FNV)
GESTUREFLOW_LAYER_CHAIN_HP0_PROBE[125]   = 0xDDE32561   (FC FNV)
GESTUREFLOW_LAYER_CHAIN_HP0_FULL_NETWORK_BOARD_PASS
```

性能计数器（`PROBE[130..133]`，约 333.333 MHz global timer）：

| 项 | 十六进制 | 十进制 ticks | 估算 |
|---|---|---|---|
| 整帧 | 0x0B1EAA2E | 186,408,494 | 约 559 ms |
| 输入准备 | 0x00081C67 | 531,559 | 约 1.59 ms |
| 权重/量化装载 | 0x0244FDF3 | 38,095,859 | 约 114 ms |
| PL 周期总和 | 0x0043EA9F | 4,452,959 | 25 MHz 下约 178 ms |

> 注意：当前 bit 是 `wide80_postprocess` 完整证明模式（`GF_FAST_RELEASE=0`），不是发布快速路径，因此整帧比历史 `writer-burst` 快速路径更长。权重装载仍是每帧 AXI-Lite 重装（约 114 ms），与架构路线 B1 一致，尚未切换到权重驻留 + PL DMA。
