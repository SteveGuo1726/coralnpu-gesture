如果后续要改板级逻辑，优先改 `current/` 下的文件，不要再直接往旧壳里堆新内容。

## 3. 当前目录职责

- `current/rtl/` 只放当前活跃 RTL。
- `current/constraints/` 只放当前活跃约束。
- `current/scripts/vivado/` 只放当前活跃 Vivado 构建脚本。
- `current/scripts/xsdb/` 只放当前活跃 XSDB 读回和烟雾测试脚本。
- `generated_rtl_official/` 保留干净官方生成物。
- `generated_rtl/` 只作为历史参考，不再当作官方边界。

## 4. 现在的判断

7Z010 这一支已经不是“先找文件、先搭框架”的阶段了。
现在应该直接围着这条链推进：

```text
current/rtl
+ current/scripts
+ 当前状态文件
+ 板上读回回归
```

这样后面再加硬件优化时，入口不会继续散。
